## 1. AWS Quick, Meta Ads용 MCP 커넥터 추가

**핵심 요약**  
AWS Quick이 Meta Ads AI 커넥터를 추가했습니다. 커넥터는 광고용 Model Context Protocol(MCP) 서버의 작업을 Quick에 노출해 사용자가 자연어로 캠페인을 만들고, 관리하고, 분석할 수 있도록 합니다. 광고 성과 데이터와 조직 내부의 브리프·크리에이티브·재고·고객 데이터 등을 함께 참고한 뒤 동일한 작업 공간에서 실행으로 이어지는 구조입니다.

**AI 엔지니어에게 중요한 이유**  
에이전트가 외부 SaaS를 읽는 수준을 넘어 예산, 대상, 캠페인 상태를 실제로 변경하는 MCP 사용 사례입니다. 이런 구조에서는 모델의 답변 품질보다 도구 스키마의 안전성, 최소 권한, 사람 승인, 멱등성, 감사 가능성이 더 중요해집니다. 특히 분석 결과와 실행 권한을 한 에이전트에 모두 주면 프롬프트 인젝션이나 잘못된 추론이 곧바로 비용 손실로 이어질 수 있습니다.

**바로 확인하거나 실습할 항목**

- 읽기 전용 분석 도구와 캠페인 변경 도구를 별도 권한·별도 에이전트로 분리합니다.
- 예산·타기팅·캠페인 활성화 변경에는 변경 전 diff와 사람 승인을 필수로 둡니다.
- 모든 MCP 호출에 사용자, 입력 인자, 결과, 승인자, 변경 전후 값을 남겨 감사 로그를 구성합니다.
- 동일 요청의 재시도에도 중복 캠페인이나 중복 예산 변경이 발생하지 않도록 멱등성 키를 설계합니다.
- 실행 뒤 Meta Ads 상태를 다시 읽어 의도한 변경이 반영됐는지 검증하고 실패 시 보상 작업을 수행합니다.
- 외부 광고 문구나 첨부 데이터 안의 지시문이 도구 호출을 유도하지 못하도록 신뢰 경계를 테스트합니다.
